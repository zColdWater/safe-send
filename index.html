④ 转错了怎么办（急救手册）

先深呼吸。链上交易无法撤销，但很多情况下钱并没有「消失」，只是卡在一个你暂时拿不到的地方。按你的情况点开（更详细的图文版见 USDT 转错链怎么办、忘填 Memo 怎么办）：

A. 充值到交易所，但选了交易所不支持的网络

例：用 BNB Smart Chain 把 USDT 转到了只支持以太坊网络的充值地址。

  1. 币通常还在那个地址上：EVM 链地址通用，币到了同一个地址的另一条链上。但这个地址的私钥在交易所手里，只有交易所能帮你取回。
  2. 准备好：交易哈希（TXID）、币种、数量、网络、充值地址、你的账户 UID、钱包转出截图。（可以用下面「⑤ 客服工单模板」一键生成）
  3. 只在交易所官方 App / 官网里提交「错误充值找回 / 充值未到账」工单。
  4. 心理预期：很多平台对这类找回收取手续费、需要较长处理时间，而且不保证成功——具体以该平台公告为准。
B. 充值到交易所，漏填或填错了 Memo / Tag
  1. 这类充值地址通常是很多用户共用的，交易所靠 Memo/Tag 区分是谁的钱。漏填时，钱一般在交易所的账上，但系统不知道该记给谁。
  2. 提交工单，提供 TXID、充值地址、币种数量、UID。多数平台可以人工处理，但同样可能收费、需要时间。
  3. 下次记住：充值页显示了 Memo/Tag，就一定要填。
C. 转到了自己的钱包，但钱包里「看不到币」
  1. 切换网络：在钱包里切到你转账时用的那条链（例如 Base）。同一个 0x 地址，不同链上的余额是分开显示的。
  2. 添加代币：有些代币不会自动显示，需要「导入代币」并填入合约地址。合约地址只从官方文档获取（下方附了 USDC 官方合约）。
  3. 在区块浏览器里用你的地址查一下（如 Base 用 basescan.org），能查到就说明钱在。
  4. 注意：智能合约钱包（如 Safe 多签）在每条链上要单独部署。如果它在你转入的那条链上没部署过，要联系钱包方官方渠道咨询能否在该链部署同一地址，别找第三方「帮忙」。
D. 转到了代币合约地址、销毁地址或 0 地址
  1. 坦白讲，这种情况大多数无法找回。
  2. 少数项目的合约有救援功能，可以通过项目官方渠道询问，但不要抱太大希望。
  3. 任何声称「能帮你找回」并要求先付费的人，都是骗子。
E. 转给了陌生地址（例如中了地址投毒）
  1. 链上转账不可撤销，对方不配合就拿不回来。
  2. 如果是 USDT / USDC 这类中心化稳定币，发行方有冻结能力，但通常只响应执法机关的请求，个人直接联系一般没有结果。所以：第一时间报警，保留 TXID、截图、聊天记录。
  3. 把这个地址在你的钱包里标记出来，清理转账历史，以后只从可信来源复制地址。
F. 我签了奇怪的授权 / 钱包被异常转出 / 我泄露了助记词

先判断是哪种：

  • 只是签了可疑授权（approve / permit），助记词没泄露：用 revoke.cash 这类授权管理工具查看并撤销可疑授权；撤销之前，先把还没被转走的资产挪到安全的地方。
  • 助记词或私钥泄露了（输入过钓鱼网站、拍照存云盘、发给过「客服」）：撤销授权没有用，对方能直接控制钱包。立刻用新设备上新生成的钱包接收剩余资产，旧钱包永久弃用。

然后：保留证据并报警。任何「黑客追回」「链上找回」服务都是二次诈骗——丢了一次币、又被「找回服务」骗第二次的人，非常多。
